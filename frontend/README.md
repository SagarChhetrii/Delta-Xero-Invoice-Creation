# Delta Xero Invoice Creation - Frontend

This directory contains the complete React frontend for the Delta Xero Invoice Creation application.

For full setup instructions, Supabase configuration, deployment steps, and project documentation, see the [main README](../README.md).

## Quick Start

```bash
npm install
cp .env.example .env
npm run dev
```

Open `http://127.0.0.1:4028/`.

## Required Environment

```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anonymous-key
```

## Commands

| Command | Description |
| --- | --- |
| `npm run dev` | Start development server |
| `npm run build` | Build production output |
| `npm run preview` | Preview the production build |
